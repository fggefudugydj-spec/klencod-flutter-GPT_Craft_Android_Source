# GPT Craft — مشروع أندرويد تجريبي

هذه نسخة أولية قابلة للتطوير من لعبة مكعبات ثلاثية الأبعاد، مكتوبة من الصفر باستخدام **Godot 4.3+ و GDScript**.

## الموجود في النسخة
- عالم مكعبات تجريبي مع أرض وأشجار بسيطة.
- حركة منظور الشخص الأول وقفز.
- أزرار لمس على الشاشة للحركة والقفز.
- سحب بالإصبع على يمين الشاشة لتحريك الكاميرا.
- تكسير المكعبات ووضع مكعبات جديدة.
- التبديل بين أربعة أنواع من المكعبات.

## فتح المشروع
1. ثبّت Godot 4.3 أو أحدث على الكمبيوتر.
2. افتح Godot ثم اختر Import.
3. اختر ملف `project.godot` من هذا المجلد.
4. شغّل المشروع بزر التشغيل.

## إخراج APK لأندرويد
1. ثبّت Android SDK و Java/JDK المتوافقين مع إصدار Godot لديك.
2. من Godot افتح Editor Settings ثم Export > Android واضبط مسارات SDK و JDK.
3. ثبّت Export Templates المطابقة لإصدار Godot.
4. من Project > Export أضف Android preset ثم صدّر APK.
5. اختبره على جهازك؛ قد تحتاج إلى تعديل إعدادات التوقيع/المعمارية حسب جهازك.

## تحكم الكمبيوتر
- W / A / S / D: حركة.
- Space: قفز.
- اضغط زر الفأرة الأيسر واسحب: تدوير الكاميرا.
- أزرار BREAK و PLACE و BLOCK تظهر على الشاشة.

## حدود النسخة الحالية
هذه ليست نسخة كاملة من Minecraft Bedrock ولا تحتوي بعد على حفظ العوالم أو كهوف أو وحوش أو تصنيع أو لعب جماعي. إنها أساس تجريبي أول قابل للتشغيل، ويجب اختبار الأداء والتحكم على جهاز Android فعلي قبل اعتبارها إصداراً جاهزاً.
